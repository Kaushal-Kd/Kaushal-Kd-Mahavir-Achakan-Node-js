## Stack

- Node.js + Fastify
- Knex + MySQL
- JWT auth + Zod validation
- Google Cloud Storage for images

## Setup

```bash
npm install
cp apps/backend/.env.example apps/backend/.env
npm run db:setup
npm run dev
```

API default: `http://localhost:4000`

Frontend lives in [Mahavir-Achakan-Electron-React](https://github.com/Kaushal-Kd/Mahavir-Achakan-Electron-React).
